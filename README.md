# Web Application for Managing Course Projects in Computer Science

## Background and Importance
- Purpose: Developed to efficiently manage course projects for Computer Science students, providing an easy and convenient platform for both students and instructors.
- Need: To facilitate the storage, search, and access of student project work and examples, making it easier for students to organize and review their projects.
- Objective: A user-friendly web application that allows students to store, search, view, and download project data over the internet.

## Technologies Used
- Frontend: ReactJS, Bootstrap
- Backend: Spring Boot
- Database: MySQL

## System Functionality
- Project Management: Students can store and manage their projects easily.
- Search Functionality: Ability to search for projects and view examples.
- CRUD Operations: Allows creating, reading, updating, and deleting project data.
- File Upload/Download: Supports uploading and downloading project files over the internet.
